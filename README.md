# Dwellers

A text-based adventure game written in Python, in the style of old 80s/90s
terminal adventures. You explore a cave through branching choices, each
leading to a new scene or one of several endings.

This is a proof-of-concept, built as a `rooms` dictionary of scenes and
choices with a small game loop driving it.

## Running it

Requires Python 3. From this folder, run:

```bash
python3 dwellers.py
```

Then type your choices at the `>` prompt as they're offered.
